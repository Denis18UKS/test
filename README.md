# Puzzle Scan

Android-приложение для поиска места отдельной детали или уже собранного фрагмента пазла по исходной картинке.

## Нестандартные детали
Приложение **не предполагает классическую форму пазла**. Сначала камера выделяет фактический внешний контур детали через GrabCut и контурную маску, затем сопоставляет изображение внутри этого контура с эталоном.

## Как пользоваться
1. Нажать **«Эталон»** и выбрать исходное фото, по которому изготовлен пазл.
2. Выбрать **«Скан детали»** или **«Скан фрагмента»**.
3. Поместить деталь/фрагмент целиком в рамку камеры и держать телефон примерно перпендикулярно детали.
4. Приложение автоматически сканирует кадр и при совпадении подсвечивает точное место на эталоне.
5. Если участок слишком однотонный и однозначно определить место нельзя, приложение не выдаёт ложный результат и предлагает отсканировать более крупный соседний фрагмент.

## Алгоритм
- сегментация произвольной формы;
- SIFT + RANSAC-гомография для текстурных деталей и крупных фрагментов;
- fallback: masked template matching по нескольким размерам и углам;
- визуальная подсветка найденного контура на исходной фотографии;
- два режима: отдельная деталь / собранный фрагмент.

Сборка: Android 8.0+ (minSdk 26), Java 17, OpenCV 4.12.
